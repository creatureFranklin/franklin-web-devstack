Dev commands cheat sheet

The most common commands you can run in this project:

Run locally (with live reload) dev 
npm install
npm run dev

# custom port:
npm run dev --port=8000

Installs dependencies and starts the dev server with Tailwind, SCSS and JS watch.

Production build prod 
npm run build

Builds Tailwind + SCSS + JS, copies static files and adds cache-busting hashes to CSS/JS.

Partial builds
  • npm run build:css
    Build Tailwind and SCSS only.
  • npm run build:js
    Bundle and minify all src/js/*.js entrypoints.
  • npm run build:static
    Copy HTML and assets from src/ to dist/.
  • npm run build:rev
    Rename JS/CSS files with hashes and update references in HTML.
Useful notes
  • Edit templates in src/*.html.
  • Custom SCSS lives in src/scss/main.scss.
  • JS entrypoints go to src/js/*.js.
  • The built site is always in dist/.

Tailwind

Tailwind in this stack uses the tw- prefix and only generates classes that are actually used in your templates and JS. Feel free to customize the setup in tailwind.config.cjs.

SCSS

Write your custom styles in src/scss/main.scss. The output is in dist/assets/css/main.css.
